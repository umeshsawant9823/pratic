SOLID Principle

SOLID is a collection of 5 object-oriented design principles that help us write clean, maintainable and reusable code.
1. Single Responsibility Principle (SRP)
2. Open/Closed Principle (OCP)
3. Liskov Substitution Principle (LSP)
4. Interface Segregation Principle (ISP)
5. Dependency Inversion Principle (DIP)

What is Design Pattern?

"A Design Pattern is a ready-made solution for a common software design problem.It helps developers write clean, reusable, flexible, and maintainable code.

Types of Design Patterns
Creational Design Pattern – Deals with object creation.
Structural Design Pattern – Deals with class and object structure/composition.
Behavioral Design Pattern – Deals with communication and interaction between objects.
